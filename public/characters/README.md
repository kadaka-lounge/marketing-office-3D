# Character portrait atlas

`team-atlas.png` was generated with GPT Image for this project. It is a 3 × 3 atlas used directly by CSS without cropping or image modification.

Cells in row order: Anda (human manager), Maya, Rio, Luna, Pixel, Atlas, Nova, Cleo, Kai. The palette reflects the manager and four divisions. These generated portraits appear in the team directory, profiles, and chat. The animated 3D bodies are Claw3D voxel models with locally adapted clothing colors; the portraits do not imply generated rigged 3D meshes.
